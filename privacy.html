Privacy Policy

Effective September 28, 2026
This is a personal, single-user automation tool with no public users. It does not collect, store, or share data belonging to anyone other than its owner, and does not run any tracking, analytics, or advertising code.

What data this tool handles

This application processes only:

  • Video files and their titles/descriptions/captions, all created by the owner, stored locally on the owner's own computer
  • OAuth access and refresh tokens issued directly to the owner by each connected platform (YouTube, TikTok, Instagram), used only to publish the owner's own videos to the owner's own accounts
  • Upload status and history (success/failure, timestamps, post links) for the owner's own videos, stored in a local database on the owner's own computer

What this tool does not do

  • It does not collect data about any other individual.
  • It does not sell, share, or transmit data to any third party other than the platform being published to, and only the minimum needed to complete that publish (the video file, its title/caption, and the owner's own access token).
  • It does not use any data for advertising, profiling, or analytics of any kind.
  • It has no public-facing website, sign-up flow, or user accounts beyond the single owner.

Storage and retention

All data is stored locally on the owner's own computer for as long as the owner chooses to keep it, and can be deleted by the owner at any time by removing the application's local files.

Third-party platforms

When this tool publishes a video to YouTube, TikTok, or Instagram, that platform's own privacy policy governs how it handles the content and account data at that point. This tool only initiates the publish using access explicitly authorized by the owner.

Changes

This policy may be updated to reflect changes in how this tool operates. As it has no external users, there is no separate notification process.

Contact

Questions can be directed to the account under which this tool is registered with each connected platform.
